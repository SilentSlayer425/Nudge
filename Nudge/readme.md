# Nudge

An offline AI productivity assistant for macOS.

Nudge uses local AI models to help users stay on task by analyzing activity context and providing private, offline accountability.

## Features

- Native macOS app
- Local AI inference
- Adaptive focus checking
- Battery-aware scheduling
- Screen activity analysis
- Goal-based productivity tracking

## Planned Tech

- SwiftUI
- ScreenCaptureKit
- CoreML / llama.cpp
- SQLite
- Local GGUF models
